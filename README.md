# Hayman Oo — Personal Portfolio 💜

A fully animated, bilingual (Burmese ⇄ English) portfolio website for **Hayman Oo**, a small business owner connecting Thailand and Myanmar.

## ✨ Features

- 🌐 **Bilingual** — one-tap toggle between မြန်မာ and English
- 🎁 **3D background** (Three.js) — floating pastel hearts & cute blind-box toys, sparkle field, mouse-follow parallax
- 🎬 **GSAP animations** — loader screen, scroll-triggered reveals (replay on scroll up & down), floating emojis, 3D-tilting business card
- 🎀 **Cute premium theme** — violet/purple palette, Quicksand font, glassmorphism cards, glow shadows, scrolling marquee
- 📍 **Location section** — embedded Google Map, opening hours (8:00 AM – 8:00 PM daily)
- 📱 **Fully responsive** — mobile to desktop

## 🛠️ Tech stack

| Tool | Purpose |
| --- | --- |
| React 19 + TypeScript | UI |
| Vite | Dev server & build |
| Tailwind CSS v4 | Styling |
| GSAP + ScrollTrigger | Animations |
| Three.js | 3D background |
| pnpm | Package manager |

## 🚀 Getting started

```bash
pnpm install
pnpm dev      # start dev server
pnpm build    # production build → dist/
pnpm preview  # preview the build
```

## 📁 Project structure
